## 遵守 GPL 证明

XJ380 通过 SYSCALL 兼容 POSIX 标准以达到兼容 Linux 应用程序的效果，仅因为 Linux 应用程序运行可能需要对应依赖，为方便大家使用，便提供一同封装的版本，这些依赖与 XJ380 完全无关，XJ380 的全部功能均不受依赖是否存在影响，依赖仅影响可能需要使用的 Linux 应用程序，XJ380 不以任何形式链接这些依赖，属于 GPL 协议中的 “聚合体” 类型，并且该说法已取得自由软件基金会（FSF）认可，不受 GPL 等协议约束。
